# HappyPolo Apps

## How do I install these formulae?

`brew install happypolo/apps/<formula>`

Or `brew tap happypolo/apps` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "happypolo/apps"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
